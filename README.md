## 🚀 **Projects Overview**

### 1️⃣ **EKS Complete Cluster**  
A fully automated Amazon EKS cluster deployment with essential cloud-native resources:

#### 🔹 **Key Resources:**
- **Amazon EKS** (Elastic Kubernetes Service)
- **Cert-Manager** for TLS certificate automation
- **Helm** for Kubernetes package management
- **Karpenter** for automated cluster scaling
- **Fargate Profile** for serverless Kubernetes workloads
- **EKS Add-ons** (VPC CNI, CoreDNS, KubeProxy)
- **Keycloak** for authentication and identity management

#### ✅ **Key Features:**
✔ Fully automated EKS deployment with Terraform modules  
✔ Dynamic workload scaling using **Karpenter & Fargate**  
✔ Secure authentication with **Keycloak**  
✔ Best practices for **networking & security** in EKS

#### ✅ **Key Features:**

## 📜 **Best Practices & Approach**

🔹 **Infrastructure as Code (IaC):** All resources are defined using Terraform for repeatability & automation.  
🔹 **Security-First Approach:** Implements IAM roles, encryption, and least-privilege access policies.  
🔹 **Scalability:** Designed for production workloads with auto-scaling & fault tolerance.  
🔹 **Observability:** Integrates **AWS CloudWatch, Prometheus, Loki, and Grafana** for monitoring & logging.
